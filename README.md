## 历史版本能力清单

> 以下能力说明仅作存档，对应文档已下线。

- 🌐 支持对接外部 MySQL 数据库
- 🚀 一键生成应用
- 🛠️ 无需部署
- 📱 移动端支持
- 🔐 权限管理
- 💰 计费调整，无单独的文档数量限制
- 📤 数据导出能力提升
- 📥 数据导入增强
- ☁️ 数据支持存储在云开发数据集合
- 🔍 数据校验和类型检查
- 🧠 一键 AI 智能分析数据
- 🛠️ 提供 SDK
- 🌐 提供 HTTP API
